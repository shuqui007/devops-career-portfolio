# Project 01 - Git Fundamentals

## Objective

Learn and demonstrate practical Git fundamentals, including local and remote repositories, repository initialization, commits, and Git history.

## Course Topics

- Git Introduction
- Local and Remote Repositories
- Git Installation
- Git Repository Initialization
- Git Log

## Practical Goals

- Install and configure Git
- Create a local repository
- Initialize a Git repository
- Create and manage commits
- Connect a local repository to a remote repository
- Push changes to GitHub
- Review repository history using Git Log
